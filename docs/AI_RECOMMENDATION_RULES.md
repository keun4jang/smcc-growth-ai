## 1. 개요

SMCC Growth Coach는 Claude API를 사용해 다음 두 가지 AI 기능을 제공한다:

1. **레퍼런스 → 콘텐츠 아이디어 전환**: 저장된 레퍼런스를 SMCC 맥락에 맞는 콘텐츠 아이디어로 변환
2. **점수 자동 제안** (Phase 2): URL/내용을 분석해 Brand Fit, Cringe Risk, Growth Potential 점수를 자동 제안

MVP에서는 기능 1만 구현한다.

---

## 2. Brand Fit Score 기준 (1~10)

SMCC 브랜드 철학과 얼마나 일치하는지 평가한다.

### 점수를 높이는 요소

| 요소 | 예시 |
|------|------|
| 건강한 변화 서사 | "작은 습관이 만드는 변화" |
| 아침 루틴 강조 | "오늘 아침 10분의 차이" |
| 커뮤니티 중심 | "함께하는 아침" |
| 부담 없는 참여 유도 | "하고 싶을 때, 하고 싶은 만큼" |
| 자기 주도적 변화 | "내 속도로, 내 방식으로" |
| 도시적 웰니스 감성 | 세련되고 현대적인 무드 |
| 술 없는 문화 | 건강한 대안 제시 |
| 따뜻한 톤 | 강요하지 않는 부드러운 메시지 |

### 점수를 낮추는 요소

| 요소 | 예시 |
|------|------|
| 커피/카페/원두 중심 | "최고의 원두 추천" |
| 상업적 판매 중심 | "지금 사면 할인" |
| 자극적 성과 강조 | "이 루틴으로 인생이 바뀌었다" |
| 불안감 조장 | "아직도 이것 모르세요?" |
| 브랜드 정체성 불일치 | 파티, 술, 과도한 인싸 문화 |

### 점수 가이드

| 범위 | 의미 |
|------|------|
| 9~10 | SMCC 그 자체. 바로 사용 가능 |
| 7~8 | SMCC답다. 약간의 톤 조정으로 사용 |
| 5~6 | 부분 일치. 상당한 각색 필요 |
| 3~4 | 방향이 다름. 신중하게 검토 |
| 1~2 | SMCC 브랜드와 맞지 않음 |

## 3. Cringe Risk Score 기준 (1~10)

낮을수록 안전. 높을수록 짜침 위험.

### 위험도를 높이는 요소

| 요소 | 예시 |
|------|------|
| 자극적 성공 서사 | "상위 1% 습관", "성공한 사람들의 루틴" |
| 불안감 조장 | "이걸 안 하면 뒤처진다" |
| 강요형 참여 | "안 오면 손해", "인생 바뀌는 기회" |
| 인싸 강요 | "요즘 다 하는 것", "트렌드 따라가기" |
| 과도한 감정 호소 | 눈물, 극적 변화 강조 |
| 무의미한 밈 사용 | 맥락 없는 트렌드 밈 |
| 공격적 CTA | "지금 당장!", "빨리 해야 해!" |
| 허위 과장 | 비현실적 결과 약속 |

### 점수 가이드

| 범위 | 의미 |
|------|------|
| 1~2 | 완전히 자연스럽고 SMCC답다 |
| 3~4 | 약간 어색하지만 수용 가능 |
| 5~6 | 짜침 요소 있음. 수정 권장 |
| 7~8 | 짜침 위험 높음. 사용 재고 |
| 9~10 | 짜침 확정. 사용 금지 |

## 4. Growth Potential Score 기준 (1~10)

팔로워 증가에 기여할 가능성 평가.

### 점수를 높이는 요소

| 요소 | 예시 |
|------|------|
| 프로필 방문 유도 | "더 알고 싶으면 프로필 확인" |
| 저장 가치 | 나중에 다시 보고 싶은 정보/영감 |
| 공유 가능성 | "이 사람한테 보내야 해" 유발 |
| 댓글 유도 | 질문, 투표, 의견 요청 |
| SMCC 궁금증 유발 | 브랜드 스토리, 커뮤니티 소개 |
| 참여 방법 명확 | 어떻게 참여하면 되는지 구체적 |
| 후킹 오프닝 | 첫 3초에 멈추게 만드는 요소 |
| 공감 유발 | "나 얘기하는 거야?" 반응 |

### 점수 가이드

| 범위 | 의미 |
|------|------|
| 9~10 | 바이럴/저장/팔로워 유입 높을 것으로 예상 |
| 7~8 | 팔로워 유입에 기여 가능 |
| 5~6 | 보통. 참여는 있지만 팔로워 전환 낮을 수 있음 |
| 3~4 | 낮은 성장 기여. 브랜드 유지용으로는 가능 |
| 1~2 | 팔로워 성장에 거의 기여 안 할 것 |

## 5. 레퍼런스 → 콘텐츠 아이디어 전환 프롬프트 구조

### 입력 데이터

```typescript
interface ConvertToIdeaInput {
  reference: {
    url: string;
    title: string;
    platform: string;
    good_points: string;
    smcc_apply: string;
    why_saved: string;
    brand_fit_score: number;
  };
}
```

### 프롬프트 구조

```
[시스템 프롬프트]
당신은 SMCC 콘텐츠 전략가입니다.

SMCC 브랜드 이해:
- SMCC는 커피 브랜드가 아닙니다. 커피는 사람들을 모이게 하는 매개체입니다.
- SMCC의 핵심: 아침 시간에 개인이 스스로 건강한 변화를 시작하고, 그 변화를 지속하는 커뮤니티
- 핵심 키워드: 아침 루틴, 건강한 변화, 커뮤니티, 자기 주도적, 부담 없는 참여
- 금지 표현: 상위 1% 습관, 인생이 바뀐다, 안 오면 손해, 불안감 조장, 커피/원두 중심
- 톤: 따뜻하고 진솔하며 강요하지 않는

[유저 프롬프트]
다음 레퍼런스를 SMCC 스타일 콘텐츠 아이디어 3개로 전환해주세요.

레퍼런스:
- URL: {url}
- 제목: {title}
- 플랫폼: {platform}
- 좋았던 점: {good_points}
- SMCC에 적용할 점: {smcc_apply}
- 저장 이유: {why_saved}

각 아이디어를 다음 형식으로 작성해주세요:

아이디어 1:
- 제목: 
- 추천 포맷: (릴스/캐러셀/피드/스토리 중 하나)
- 핵심 콘셉트: (1~2문장)
- 훅 (첫 3초): 
- 콘텐츠 구성: (3~5단계)
- 캡션 아이디어: 
- SMCC 해시태그 제안: 
```

### 응답 파싱

Claude API 응답을 구조화된 JSON으로 파싱해 `content_ideas` 테이블에 저장.

## 6. 점수별 추천 액션

### Brand Fit Score 기반

| 점수 | 앱 내 안내 메시지 |
|------|----------------|
| 8~10 | "SMCC 브랜드와 잘 어울리는 레퍼런스예요. 바로 활용해보세요." |
| 5~7 | "방향은 맞지만, SMCC 톤으로 조정이 필요해요." |
| 3~4 | "SMCC 방향과 조금 달라요. 신중하게 검토해보세요." |
| 1~2 | "SMCC 브랜드에 맞지 않는 레퍼런스예요. 참고 정도로만 활용하세요." |

### Cringe Risk Score 기반

| 점수 | 앱 내 안내 메시지 |
|------|----------------|
| 1~3 | "자연스럽고 SMCC다운 표현이에요." |
| 4~6 | "약간의 짜침 요소가 있어요. 표현을 다듬으면 좋아요." |
| 7~8 | "짜침 위험이 높아요. 사용 전 팀원과 검토하세요." |
| 9~10 | "SMCC 브랜드 이미지를 해칠 수 있어요. 사용을 피하세요." |

### Growth Potential Score 기반

| 점수 | 앱 내 안내 메시지 |
|------|----------------|
| 8~10 | "팔로워 유입 가능성이 높아요. 우선 제작을 고려해보세요." |
| 5~7 | "적당한 성장 기여가 예상돼요." |
| 1~4 | "팔로워 유입보다 브랜드 유지 목적에 적합해요." |

## 7. AI 호출 최적화 (무료 플랜 기준)

- AI 아이디어 생성은 사용자 요청 시에만 호출 (자동 호출 없음)
- 동일 레퍼런스에 대한 중복 호출 방지 (캐싱 또는 재생성 확인 팝업)
- 프롬프트는 최소한의 토큰으로 구성
- 응답은 `content_ideas` 테이블에 저장해 재호출 방지
