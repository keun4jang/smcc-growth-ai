# BRAND_GUIDE.md — SMCC 브랜드 가이드

---

## 1. 브랜드 핵심 문장

> "SMCC는 커피를 파는 곳이 아니다.
> 아침을 시작하는 사람들이 모이는 곳이다.
> 변화는 거창하지 않아도 된다.
> 오늘 아침, 여기서, 한 걸음."

---

## 2. 브랜드 철학

| 항목 | 내용 |
|------|------|
| 핵심 정체성 | 건강한 변화를 시작하고 지속하는 아침 커뮤니티 |
| 커피의 역할 | 브랜드 본질이 아닌, 사람들을 모이게 하는 매개체 |
| 참여 방식 | 강요하지 않고, 자연스럽게, 부담 없이 |
| 지향하는 문화 | 술 없는 문화, 도시적 웰니스, 자기 주도적 라이프스타일 |
| 커뮤니티 성격 | 나만의 루틴을 만들고 싶은 사람들의 조용한 모임 |

---

## 3. 브랜드 키워드

### 긍정 키워드 (콘텐츠에 적극 활용)

- 아침 루틴
- 건강한 변화
- 자기 주도적
- 부담 없는 시작
- 꾸준함
- 커뮤니티
- 도시적 웰니스
- 조용한 참여
- 일상의 리듬
- 작은 습관의 힘

### 부정 키워드 (콘텐츠에서 반드시 피함)

- 상위 1% 습관
- 인생이 바뀐다
- 안 오면 손해
- 성공 공식
- 인싸 문화
- 불안감 조장
- 자극적 성과
- 과도한 동기부여

## 5. 타이포그래피 방향

무료 폰트만 사용한다. Google Fonts 기준.

| 용도 | 폰트 후보 | 특징 |
|------|----------|------|
| 제목/헤더 | Pretendard (한국어), Plus Jakarta Sans (영문) | 정돈되고 현대적 |
| 본문 | Pretendard, Inter | 가독성 높고 중립적 |
| 강조/에디토리얼 | DM Serif Display | 에디토리얼 감성 |
| 숫자/데이터 | Inter, Tabular Nums | 숫자 정렬에 적합 |

### 타이포그래피 원칙

- 폰트 종류는 최대 2개로 제한
- 한국어 텍스트는 Pretendard 우선 사용
- 폰트 크기는 디자인 시스템의 타입 스케일을 따름

## 6. 톤앤매너

### UI 텍스트 톤

- 친근하지만 과도하게 캐주얼하지 않다
- 불필요한 설명을 줄이고 간결하게
- 사용자를 다그치거나 강요하는 표현 금지
- 성취감을 줄 때도 조용하게 ("좋은 레퍼런스네요" > "대박! 완벽한 레퍼런스!")

### 에러/알림 메시지 톤

- 에러: 차갑거나 기술적 용어 대신 부드럽게 ("저장이 잘 안됐어요. 다시 시도해볼까요?")
- 성공: 간결하게 ("저장됐습니다")
- 안내: 설명형보다 행동 유도형

## 7. 브랜드 무드 점수 기준 (Brand Fit Score)

1~10점 척도.

| 점수 | 의미 |
|------|------|
| 8~10 | SMCC 철학과 완벽하게 일치 |
| 5~7 | 부분적으로 맞음. 조정 후 사용 가능 |
| 3~4 | 방향이 다름. 신중하게 검토 |
| 1~2 | SMCC 브랜드에 맞지 않음 |

점수가 높아지는 요소:
- 건강한 변화, 아침 루틴, 커뮤니티 중심 메시지
- 부담 없는 참여 유도
- 따뜻하고 도시적인 무드
- 자기 주도적 변화 서사

점수가 낮아지는 요소:
- 커피/카페/원두 중심 내용
- 상업적이고 자극적인 메시지
- 과도한 성과/동기부여 강조
- 술/파티 문화 연상

---

## 8. 짜침 위험도 기준 (Cringe Risk Score)

1~10점 척도. 낮을수록 안전.

| 점수 | 의미 |
|------|------|
| 1~3 | 자연스럽고 SMCC답다 |
| 4~6 | 약간 부자연스러움. 수정 권장 |
| 7~8 | 짜침 위험 높음. 사용 재고 |
| 9~10 | 짜침 확정. 절대 사용 금지 |

위험도를 높이는 요소:
- "안 오면 손해", "인생이 바뀐다", "상위 1%" 등 자극적 문구
- 불안감 조장 ("이것도 모르세요?")
- 인싸 강요, 트렌드 추종 강요
- 과도한 감정 호소
- 브랜드 정체성 없는 밈 사용
