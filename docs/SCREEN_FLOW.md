```

  S02 Dashboard ←─────────────────────────┐
    │                                      │
    ├──→ S03 Reference Library             │
    │       │                              │
    │       ├──→ S04 Reference Detail      │
    │       │         │                    │
    │       │         └──→ S06 AI Ideas ──→│
    │       │                              │

    │                                      │
    ├──→ S05 Content Analysis              │
    │                                      │
    ├──→ S06 AI Content Ideas              │
    │       │                              │

    │                                      │
    ├──→ S07 Content Calendar              │

    ├──→ S08 Brand Guide                   │
    │                                      │
    └──→ S09 Settings ────────────────────→ 로그아웃 → S01
```

---

## 로그인/비로그인 분기

- 로그인 상태 확인은 앱 진입 시 Supabase 세션으로 처리
- 비로그인 상태에서 `/` 이외 경로 접근 시 `/login`으로 리다이렉트
- 로그인 성공 시 원래 접근하려던 경로로 리다이렉트
