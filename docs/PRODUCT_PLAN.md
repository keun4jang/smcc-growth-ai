# PRODUCT_PLAN.md — SMCC Growth Coach 제품 기획

---

## 1. 배경과 목적

SMCC 콘텐츠 팀은 인스타그램 팔로워를 늘리고 브랜드 무드를 유지하면서 좋은 콘텐츠를 꾸준히 만들어야 한다.
현재는 레퍼런스를 모으고, 아이디어를 정리하고, 캘린더를 운영하고, 성과를 기록하는 도구가 분산되어 있다.

**SMCC Growth Coach**는 이 모든 작업을 하나의 작업실에서 할 수 있도록 만드는 내부용 앱이다.

---

## 2. SMCC 브랜드 철학

SMCC는 커피 브랜드가 아니다.
커피는 사람들을 모이게 하는 자연스러운 매개체일 뿐이다.

SMCC의 핵심 가치:
- 아침 시간에 개인이 스스로 건강한 변화를 시작하는 것
- 그 변화를 혼자가 아니라 커뮤니티와 함께 지속하는 것
- 강요하지 않고, 자연스럽게, 부담 없이 참여하게 하는 것
- 술 없는 문화, 도시적 웰니스, 자기 주도적 라이프스타일

따라서 앱의 모든 콘텐츠 추천, 점수, 텍스트는 커피/카페/원두 중심이 아니라
**건강한 변화, 아침 루틴, 커뮤니티, 사람의 변화** 중심이어야 한다.

---

## 3. 타겟 사용자

- SMCC 콘텐츠 팀 내부 (1~3명 소규모 팀)
- 인스타그램 콘텐츠 기획/제작 담당자
- 브랜드 방향을 이해하고 콘텐츠 성장을 책임지는 사람

외부 공개 서비스가 아니다. 내부 작업 도구다.

---

## 4. 핵심 목표

1. **SMCC 인스타그램 팔로워 증가** — 팔로워 증가에 도움이 되는 콘텐츠 유형 파악
2. **브랜드 무드 유지** — Brand Fit Score로 콘텐츠 방향이 SMCC답게 유지되는지 관리
3. **좋은 레퍼런스 저장 및 관리** — 흩어진 레퍼런스를 한 곳에서 체계적으로 관리
4. **레퍼런스 → 콘텐츠 아이디어 전환** — 레퍼런스를 SMCC 맥락에 맞게 재해석
5. **콘텐츠 성과 기록 및 분석** — 수동 입력 기반 성과 추적

---

## 5. 성공 지표

| 지표 | 기준 |
|------|------|
| 팔로워 증가율 | 월별 순증가 추적 |
| 콘텐츠 저장/전환율 | 저장된 레퍼런스 중 Converted 비율 |
| Brand Fit Score 평균 | 발행 콘텐츠 평균 7점 이상 유지 |
| Cringe Risk Score 평균 | 발행 콘텐츠 평균 3점 이하 유지 |
| 주간 콘텐츠 캘린더 채움률 | 계획 대비 실행 비율 |

---

## 6. MVP 범위

### 포함

- 로그인 (Supabase Auth)
- 레퍼런스 저장/관리 (Reference Library)
- 레퍼런스 상세 분석 및 점수 기록
- 레퍼런스 → 콘텐츠 아이디어 전환
- 콘텐츠 성과 수동 입력
- 주간 콘텐츠 캘린더
- Brand Fit / Cringe Risk / Growth Potential 점수
- 브랜드 가이드 화면
- 기본 대시보드

### 제외 (Phase 2 이후)

- Instagram API 자동 연동
- 팀 협업 기능 (코멘트, 승인 워크플로우)
- 자동 썸네일 크롤링
- 모바일 앱
- 알림 기능
- 외부 공유 기능

---

## 7. 핵심 제약

- 무료 도구만 사용
- Supabase Free Plan 기준 (500MB DB, 1GB 스토리지, 50K 월간 활성 사용자)
- Instagram API 자동 연동 MVP 제외
- 성과 데이터는 사용자가 Meta Business Suite에서 확인 후 수동 입력
