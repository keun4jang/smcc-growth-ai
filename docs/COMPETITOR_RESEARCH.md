# COMPETITOR_RESEARCH.md — 경쟁 앱/참고 서비스 분석

---

## 분석 기준

각 서비스에서 SMCC Growth Coach에 참고할 기능/UX를 추출하고,
적용할 것과 적용하지 않을 것을 명확히 구분한다.

---

## 1. Later

**카테고리:** SNS 콘텐츠 스케줄링 도구

### 참고할 점
- **Media Library**: 이미지/영상을 라이브러리로 정리하는 방식 → Reference Library 구조에 적용
- **Labels & Notes**: 콘텐츠에 레이블과 메모를 붙이는 방식 → 태그/컬렉션/메모 기능에 적용
- **Starred Media**: 즐겨찾기로 빠르게 접근 → 즐겨찾기 기능에 적용
- **콘텐츠 상태 표시**: Draft → Scheduled → Published 흐름 → 콘텐츠 상태값에 적용

### 적용하지 않을 것
- 자동 게시 기능 (Instagram API 연동) — MVP 제외
- 유료 분석 리포트 기능

---

## 2. Buffer

**카테고리:** SNS 스케줄링 및 분석

### 참고할 점
- **주간/월간 캘린더 뷰**: 날짜별 콘텐츠 배치가 직관적 → Content Calendar 화면에 적용
- **채널별 큐 관리**: 콘텐츠 포맷(릴스, 캐러셀 등)별 분류 → 포맷 필터에 적용
- **간결한 사이드바 내비게이션**: 기능 접근이 단순하고 명확 → 앱 레이아웃에 적용

### 적용하지 않을 것
- 멀티 채널(Twitter, LinkedIn 등) 관리 — SMCC는 Instagram 중심
- 팀 협업 승인 워크플로우 — MVP 제외

---

## 3. Metricool

**카테고리:** 무료 SNS 분석 도구

### 참고할 점
- **무료 기본 분석 구조**: 핵심 지표(도달, 참여율, 팔로워 증가)를 깔끔하게 보여주는 방식
- **콘텐츠별 성과 비교**: 같은 기간 콘텐츠들의 성과를 비교하는 방식 → Content Analysis에 적용
- **성과 요약 카드**: 주요 지표를 카드 형태로 보여주는 방식 → Dashboard에 적용

### 적용하지 않을 것
- 자동 Instagram API 연동 — MVP에서 수동 입력으로 대체
- 광고 성과 분석 기능

---

## 4. Planable

**카테고리:** 콘텐츠 검토/승인 협업 도구

### 참고할 점
- **콘텐츠 상태 관리**: Draft, Review, Approved, Scheduled 상태 흐름이 명확
- **캘린더 + 리스트 뷰 전환**: 같은 콘텐츠를 캘린더 또는 리스트로 볼 수 있는 방식
- **코멘트 기능**: 콘텐츠 피드백을 기록하는 방식 → 메모/분석 기능에 부분 적용

### 적용하지 않을 것
- 팀원 승인 워크플로우 — MVP는 1인 운영 기준
- 실시간 협업 편집

---

## 5. Milanote

**카테고리:** 크리에이티브 작업 보드 / 무드보드 도구

### 참고할 점
- **자유로운 레퍼런스 수집**: URL, 이미지, 텍스트를 보드에 자유롭게 모으는 방식
- **컬렉션 개념**: 레퍼런스를 주제별 컬렉션으로 묶는 방식 → Reference Library 컬렉션에 적용
- **카드형 레이아웃**: 레퍼런스를 카드로 표시하는 방식 → Reference Library 카드 UI에 적용
- **시각적 여백**: 정보를 빽빽하게 채우지 않는 여유 있는 레이아웃

### 적용하지 않을 것
- 무한 캔버스 방식 — 대신 Grid/List 방식으로 구조화
- 드래그앤드롭 자유 배치 — MVP에서 제외

---

## 6. Raindrop

**카테고리:** 북마크/레퍼런스 관리 도구

### 참고할 점
- **컬렉션 + 태그 이중 구조**: 컬렉션으로 큰 분류, 태그로 세부 분류하는 방식 → Reference Library에 그대로 적용
- **빠른 검색**: 제목, URL, 태그로 즉시 검색 → 검색/필터 기능에 적용
- **다양한 뷰 모드**: Grid, List, Masonry 등 뷰 전환 → 뷰 모드 전환 기능에 적용
- **플랫폼별 자동 분류**: URL에서 플랫폼(Instagram, YouTube 등) 자동 감지 → 플랫폼 감지에 적용

### 적용하지 않을 것
- 공개 공유 기능 — 내부 도구이므로 불필요
- 브라우저 확장 프로그램 — MVP에서 제외
